## ✨ Features

> A fully integrated desktop application combining analytical geomechanics with a modern PyQt5 GUI.

<br>

- ⚙️ **Coupled THM Solver** — Modified Kirsch equations for thermo-hydro-mechanical stress analysis
- 📈 **Spatial Stress Profiling** — Radial & tangential stress distribution around LRC caverns
- 🔄 **Cyclic Fatigue Analysis** — Steel liner Von Mises stress vs. S355 yield limit across H₂ cycles
- 🧱 **Plastic Zone Estimation** — Mohr-Coulomb failure criterion via Kastner-type analytical model
- 💾 **Scenario Database** — Full SQLite CRUD: save, load, and reset simulation scenarios
- 🔐 **Password Protection** — Secure access control (default: `admin`)
- 🎨 **Multi-Theme UI** — Classic · Dark · Pro · Orange · Pink
- 🔍 **Dynamic Zoom** — Adju
